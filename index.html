Un bocal, c'est une liste de liens qu'on remplit à plusieurs : recettes, sorties, vidéos…

Ouvrir dans Bocal

Bocal ne s'est pas ouvert ? Le code est copié. Ouvre Bocal toi-même, touche « J'ai un code d'invitation » et colle le code.

Tu es dans le navigateur d'une autre app, qui ne sait pas ouvrir Bocal. Ouvre cette page dans Chrome (menu ⋮, « Ouvrir dans le navigateur »), ou copie le code et entre-le dans Bocal : « J'ai un code d'invitation ».

Tu es dans le navigateur d'une autre app : il bloque souvent l'ouverture de Bocal. Ouvre cette page dans Safari (menu ··· ou icône boussole, « Ouvrir dans Safari »), ou copie le code et entre-le dans Bocal : « J'ai un code d'invitation ».

Le bouton « Ouvrir dans Bocal » ne marche pas ? Copie le code, ouvre Bocal, touche « J'ai un code d'invitation » et colle-le. Pas encore l'app ? Installe Bocal depuis l'App Store ou Google Play.
